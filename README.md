# Blinkit Sales & Rider Performance Dashboard | Excel

## Project Overview
An Excel dashboard designed to analyze city-wise sales, rider performance, customer ratings, and delivery efficiency for 2025.

## Key Performance Indicators
- Total Delivered Orders
- Average Customer Rating
- Total Order Amount
- Actual vs. Promised Delivery Time

## Dashboard Features
- Top 5 riders by order amount
- Top riders by average customer rating
- City-wise sales contribution
- Monthly sales trend
- City and month filters for interactive analysis
- City-wise comparison of actual and promised delivery time
